# Marketing Assets — WiserFiles

## Elevator pitch

WiserFiles is a privacy-first PDF toolkit and an AI research studio. Run 25 PDF tools mostly in your browser without uploading files, or write papers in a LaTeX + Python + C++ workspace with a real code editor, AI writing, peer review, live collaboration, computed figures, and one-click import of existing projects — all free.

## Key differentiators

1. **Privacy-first**: most PDF processing runs client-side; files auto-delete.
2. **A real editor**: CodeMirror 6 with fast, caret-perfect editing, line numbers, and syntax highlighting for LaTeX, Python, and C++.
3. **Import anything**: drop in a full LaTeX/Overleaf zip (chapters, figures, appendices) and keep working.
4. **Multi-file code**: full C++ and Python projects (multiple source files, headers, imports) compile and run.
5. **AI research studio**: writing assistant, simulated peer review, code assistant.
6. **Live collaboration**: real-time cursors + edits without a WebSocket server.
7. **Reproducible research**: Python/C++ code + computed figures + LaTeX in one place.
8. **Free**: no watermarks, no daily limits on PDF tools, no account needed.

## Feature bullets (for landing pages)

- 25 free PDF tools: merge, split, compress, OCR, sign, redact, convert, compare, rotate
- Voice search to find any tool instantly
- LaTeX + Python + C++ editor with live code execution and proper syntax highlighting
- Import a full LaTeX project (zip) — chapters, figures, and appendices all come along
- Multi-file C++/Python projects compile and run in the browser
- AI writing: summarize, rewrite, expand, improve grammar
- AI peer review: strengths, weaknesses, and a score before you submit
- Real-time collaboration: cursors and edits with co-authors
- Computed figures: matplotlib plots auto-embedded in your paper
- Version history with visual diffs
- DOI citation import and CSV-to-LaTeX tables
- Export to Word (.docx) or Markdown
- Journal word-limit tracking
- Guest quotas (free AI uses) with higher limits for registered users
