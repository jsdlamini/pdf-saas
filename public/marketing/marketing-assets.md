# Marketing Assets — WiserFiles

## Elevator pitch

WiserFiles is a privacy-first PDF toolkit and a real research studio. Convert, merge, sign, and redact PDFs mostly in your browser — nothing uploaded — or write papers in a LaTeX + Python + C++ editor with a live PDF beside your code, GitHub sync, and AI assistance. Free.

## Key differentiators

1. **Conversions that are actually usable**: PDF → Excel extracts real tables into spreadsheet cells; PDF → PowerPoint builds real titled/bulleted slides; PDF → Word preserves headings, lists, and tables. No text dumps.
2. **Real redaction**: redacted text is permanently removed and unrecoverable — not a black box over a rasterised page.
3. **A real editor**: CodeMirror 6 for LaTeX, Python, and C++ with live PDF preview and instant incremental compile.
4. **Privacy-first**: most PDF processing runs in your browser; files auto-delete.
5. **Offline**: 20 of 25 PDF tools work fully offline — no account, no connection.
6. **Import anything**: drop in a full LaTeX/Overleaf zip and keep working.
7. **AI research studio**: writing assistant, simulated peer review, code assistant.
8. **Live collaboration**: real-time cursors + edits, version history with visual diffs.
9. **Free**: no watermarks, no daily limits on PDF tools, no account needed.
